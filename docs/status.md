## Что есть
- Ядро `src/core`: модель C-γ (тип B пересчитывается), чтение/запись IES и LDT, `summarize()`, проверки файлов,
  `beam.ts` — угол луча / поля (предварительно, для сводной таблицы).
- `src/core/ops.ts`: нормировка, отражение, повороты Z/X/Y, симметризация, сглаживание, смена сетки (`applyOp(p, OpSpec)`), сложение (`sumBodies`).
- `src/batch`: движок пакета `run.ts`, рецепты, варианты, имена, графики пакета, сводная таблица, Web Worker.
- Графики `src/charts`: сцена → SVG / PDF / EPS / PNG; оформление «каталог MAYTONI» и стандартное; `body3d.ts`.
- Интерфейс `src/app`: меню Файл / Правка / Вид / Фотометрия / Пакет / Формат / Окно / Справка; вкладки Паспорт / Таблица /
  Полярная / Линейная / 3D-тело / Операции (Ctrl+1…6); окно «Пакетная обработка» (`components/BatchPanel.tsx`).

## Договорённости
- Сайт обновляется 3–5 мин после `git push` (сборка с тестами) + до 10 мин кэш GitHub Pages (Ctrl+F5).
- Шрифт графиков — Suisse Intl (коммерческий, в репозиторий не кладётся). Символы, которых нет в шрифте (Φ, γ), — из Roboto.
- EPS — текст всегда кривыми. PDF со шрифтом CFF (OTF) — тоже кривыми.
- Смещения при сложении пока влияют только на размеры светящей части; расчёты на конечном расстоянии — этап 6.
