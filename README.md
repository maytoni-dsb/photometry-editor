# Photometry Editor

Онлайн-редактор фотометрических файлов IES и LDT (EULUMDAT): просмотр, редактирование,
конвертация, пакетная обработка, генерация вариантов и векторный экспорт графиков.
Вся обработка идёт в браузере — файлы не покидают компьютер пользователя.

Техническое задание — [docs/tz.md](docs/tz.md) (копия документа ТЗ), решения и соглашения — [docs/decisions.md](docs/decisions.md),
состояние — [docs/status.md](docs/status.md), порядок работы — [docs/workflow.md](docs/workflow.md).

## Состояние

| Этап | Содержание | Статус |
| --- | --- | --- |

| 5 | Пакетная обработка: рецепты, конвертация IES ↔ LDT, генерация вариантов, пакетный экспорт графиков, сводная таблица CSV / XLSX и отчёт проверки; фоновый поток, ZIP | сделано (v0.10), на приёмке |
| 6 | Расчёты (UGR, BUG, изолюксы…) | — |
| 7 | Отчёты | — |

## Сайт

Сайт собирается и публикуется на GitHub Pages автоматически при каждом изменении ветки `main`
(`.github/workflows/pages.yml`). Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.
Адрес: `https://<владелец>.github.io/<репозиторий>/`.

Если вместо сайта пустая страница или «Загрузка…» с подсказкой — Pages публикует исходники ветки
без сборки: переключите Source на **GitHub Actions** и дождитесь зелёного запуска «Pages» на вкладке Actions.

Какая сборка опубликована, видно в шапке сайта: версия и короткий хеш коммита (например, «v0.4.1 · 59ee15d»).
Если после `git push` там старый хеш — запуск «Pages» ещё идёт или упал (вкладка Actions), либо браузер
показывает страницу из кэша (до 10 минут; Ctrl+F5).

## Шрифт Suisse Intl

Фирменный шрифт графиков — Suisse Intl. Он коммерческий и в репозиторий не входит: на сайте нажмите
«Взять Suisse Intl с компьютера» (Chrome / Edge, шрифт должен быть установлен) или загрузите файлы
OTF / TTF в окне «Стиль графиков». Пока шрифт не подключён, графики рисуются встроенным Roboto.

## Как обновить репозиторий из bundle

Каждая новая версия приходит файлом `photometry-editor.bundle`.

Первый раз:

```bash
git clone photometry-editor.bundle photometry-editor
cd photometry-editor
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git push -u origin main
```

Дальше, после каждого нового bundle (положите его рядом с папкой репозитория):

```bash
cd photometry-editor
git pull ../photometry-editor.bundle main
git push
```

## Для разработки

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev                 # сайт локально: http://localhost:5173
npm run build               # сборка сайта в dist/
npm test                    # автотесты
npm run typecheck           # проверка типов
npm run audit -- <папка>    # проверить библиотеку файлов, отчёт в reports/
npm run charts -- <папка>   # построить графики всех файлов папки в reports/charts
PHOTOMETRY_LIBRARY=<папка> npm test   # прогнать тесты на реальной библиотеке
```

Реальные файлы заказчика в репозиторий не кладутся (папки `private-data/` и `reports/` в `.gitignore`).
